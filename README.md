# Ludoaventura

Petits jeux pour apprendre en s'amusant, organisés en onglets.

- Site en ligne : https://florito32.github.io/ludoaventura/
- 1er jeu : [tables de multiplication](https://florito32.github.io/ludoaventura/multiplication/)

Ajouter un jeu : créer un dossier à la racine (ex. `addition/`), puis ajouter son onglet dans la barre `<nav class="tabs">` de chaque page.
